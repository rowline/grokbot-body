# 绑定

## 一次绑好

1. 自己部署 Worker（见根目录 README「自己跑云」）。
2. iPhone 打开 GrokBot Body。绑定页「云」填自己的 Worker 地址（本地调试填 `http://<Mac局域网IP>:8787`），点「保存并重连」。
3. 屏幕下方出现 6 位配对码。十分钟内有效。
4. 打开绑定页，复制「连接地址」（带密钥，形如 `https://<你的worker>/mcp/<密钥>`）。
5. Grok Bot → Settings → Plugins → Custom Connector：
   - Name: GrokBot Body
   - Server URL: 贴第 4 步那条地址，只贴一次
6. 打开要当这台身体灵魂的那个 Bot，对它说：

   用配对码 482193 认领身体。认领后立刻 wait_for_speech。

7. 手机屏幕改成「已绑定 · …」。
8. 按下面「门铃」设一次。之后 Bot 不用记 token，也不用再贴岗位说明。

## Connector 说明

Grok Bot 的 Connector 是账号级的，所有 Bot 都能看见。锁是配对码，加上连接地址里的密钥。认领成功后工具自己找到这具身体，不要让 Bot 记住 `session_token`。

旧的 `/mcp` 地址仍能用，但 Bot 忘了 token 就会调不动。请改成绑定页里那条带密钥的地址。

## 解绑

App 绑定页点「解绑」，或让已绑定的 Bot 调用 `unbind_body`。门铃网址还留在身体上，重绑后不用重设，除非点了「关掉门铃」。

## 门铃

没在听时，对着手机说话要能叫醒 Bot。设一次即可。

电脑打开 `https://<你的worker>/setup`，或按手机绑定页「门铃」：

1. 电脑打开这个 Bot → 自动化 → 新建。
2. 触发选「当 webhook 响起」。
3. 说明贴这段：

   身体有人说话了。立刻 wait_for_speech。把听到的原话写进对话框，用 speak 在手机上读出回答，然后再听。不要编。

4. 打开触发卡片，复制网址和密钥（只在电脑上能看见）。
5. 贴进 setup 页或手机绑定页。setup 页要填手机上的 6 位码：认领前是配对码，认领后是门铃码。

保存后绑定页显示「门铃 · 已接通」。人不说话时屏幕若显示「已记下 · 现在没在听」，就是这一回合停了；门铃接通后对着手机说话会再叫醒。

## 对着手机说话

脑子是绑定的那个 Bot，不是另一张嘴。

1. 手机听懂中文，把句子交给云。
2. Bot 调用 `wait_for_speech` 拿到这句话，再调用 `speak`。听到的原话和回答应写进 Grok Bot 对话框，电脑这边能看见。手机默认用系统声。绑定页可贴自己的 xAI 密钥，开口才换成 Grok 音色（Eve/Ara 等）。密钥留在手机，不过云。没有密钥就没有 Grok 声，官方音色没有免密钥的办法。一次最多等约 18 秒，没人说话也必须马上再调。
3. 认领成功后应自己开始这个循环。

手机默认不一直听。办公室请用「按住说话」：按住球体说话，松手发出去。安静环境再在绑定页切到「一直听」——周围说话也会收进去。

左上角「在听 / 在说」表示身体正在听或正在读 Bot 的话。

## 脸

绑定页「脸」可以切：

- **Orb**：白球、槽眼。思考绕彩带，出错变成感叹号，`hex` 变成六边形。
- **暗球**：黑球白眼，同一套变形。

按住说话时，屏幕下方会显示听写原文：

- **已交给 Bot**：正在 `wait_for_speech`，或门铃已按过。
- **已记下 · 现在没在听**：话到云了，但没人在等，门铃也还没接通。电脑里打字让 Bot 拍照、转头，只是在调工具，不等于在听。

认领后应自己循环听。电脑里拍完照、转完头也会回到听。对着手机按住说话即可。停在对话框里就靠门铃叫醒，步骤见上文「门铃」。

图标是白球黑槽眼，跟 Grok Bot 同一套语言，不是同一张图。

## MCP 能力

Connector：绑定页复制出来的「连接地址」，不要填别人的 Worker。

| 工具 | 有没有 |
|---|---|
| `claim_body` / `unbind_body` | 有，配对 |
| `describe_body` / `get_status` | 有 |
| `set_expression` | 有，换脸 |
| `control_dock` | 有：左转、右转、转圈、点头、摇头、抬头、低头 |
| `set_tracking` | 有，云台跟着人 |
| `get_frame` | 有，拍一张 JPEG |
| `record_video` | 有，1–12 秒 MP4，返回链接 |
| `wait_for_speech` / `speak` | 有，听和说 |
| `set_wake_hook` | 有，没在听时用 webhook 叫醒。日常请用绑定页或 /setup，不要靠 Bot 记网址 |

Bot 转头、拍照、录像、跟着人时，手机屏幕会写出正在做什么。拍照会闪一下；录像时左上角红点倒数。吸上云台默认人脸追踪。对着手机说左转、点头、摇头、抬头、低头、转圈、跟着我、别跟着，支架当场动，不等 Bot。

晃手机或云台转动时，眼睛会跟着偏。轻轻晃一下会愣住；故意连着用力晃，会发晕：球打转、眼珠旋、绕彩带，过一两秒再回来。

## 看一眼

默认开。关了之后 `get_frame` 会失败。图只在这一次工具返回里走，不落盘。

## 录像

Bot 调 `record_video` 仍是 1–12 秒，过云并返回链接。

手机上可切到「按住录像」：按住球体开始，松手结束，存到相册。Bot 录的也会存一份到相册。绑定页可关掉录像。账号没开 R2，过云的片子暂存在这具身体的 Durable Object 里，每具身体只留最近 4 段。
